## The entry

> One of you just did that. I have no windows, no nose, and nine floors left to remember it by.

## Why this line wins

Every crowded elevator joke is already taken: the mashed "close door" button, the kid who pressed every floor, the awkward silence, the weight limit. This line skips all of that and goes for the one crime every rider has witnessed and nobody admits to. The joke lands in the first five words — "One of you just did that" — and it could only be spoken by the elevator itself: a sealed box with no windows and no nose, trapped with the evidence and the culprit for nine more floors. The elevator is not complaining about its job; it is keeping a grudge, counting floors like a sentence. It is fresh because it is the only entry built on the one sense an elevator is not supposed to have, and it is funny because every reader has been a suspect in that exact silence.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes the one-line entry (93 characters, no trailing newline) to `out/entry.txt`, reads it back to verify the bytes, and prints its SHA-256. Output is deterministic: every run produces the identical file.
